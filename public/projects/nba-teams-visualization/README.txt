Put this project's files in this folder, then push.
- A PDF whose filename contains "poster" (e.g. poster.pdf) is shown as the Poster.
- Any other PDF (e.g. report.pdf) is shown as the Report.
- An image (e.g. cover.png / .jpg / .webp) is shown on the project card and page.
  If there are several images, name the one you want "cover".
